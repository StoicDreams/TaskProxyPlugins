### Make the plugin

<webui-page-segment>

1. Copy `plugins/jira` to `plugins/<name>`, and rename the crate in its `Cargo.toml`. The workspace picks up every folder in `plugins/`.
2. In `plugin.json`, set the `id` (lowercase letters, digits, and dashes), `name`, `version` (the same as `Cargo.toml`), `description`, and `category`, such as `issue-tracking`.
3. List only what it needs under `permissions`: the `hosts` it calls, the `variables` the user enters in its settings (mark tokens `secret`), and any `git` access (`currentBranch`, `createBranch`).
4. List its `pages`. Mark a page `hidden` when it is only opened from another page.
5. Implement `Plugin` (`render`, `action`, and `branch_info` if it `contributes` `gitBranchInfo`), and end `lib.rs` with `export_plugin!(MyPlugin);`.
6. Write tests with a fake `Host`, as the Jira plugin does in `testing::FakeHost`.

Icons are Task Proxy's: browse them at `https://cdn.myfi.ws/icons`.

</webui-page-segment>

### Check it

<webui-page-segment>

```pwsh
./scripts/publish.ps1 -SkipApp
```

Then install `dist/<id>` in Task Proxy with **Plugins → Install from folder**.

</webui-page-segment>

### Give it a page on TaskProxy.com

<webui-page-segment>

Every plugin gets a page in the website's **Plugins** menu, in its category's folder:

1. Add a `demo.rs` like the Jira plugin's, and an `examples/demo.rs` that writes its screens to `../TaskProxyApp/tools/capture/fixtures/<id>`.
2. Add its captures to TaskProxyApp's `tools/capture/plugin-screenshots.capture.mjs`, saved as `img/plugins/<id>/*.webp`.
3. In the website, add `webapp/d/plugins/<category>/<id>.md`, its link in `webapp/root_files/nav.json` under **Plugins** and its category folder, a card on `webapp/d/plugins.md`, and its address in `sitemap.xml`.

</webui-page-segment>
